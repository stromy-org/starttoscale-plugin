How to react

01

Accent colour

Navy + amber-gold is the finance-category default. These keep the navy but explore a more ownable second signal — warmer coppers, a muted brass, a cool petrol, an earthy terracotta or a calm sage. Each is shown on dark, on light, as text, as a rule, and on a mini cover. A1 is today's amber (Direction 0).

02

Typography pairing

Display + body + the small-title / eyebrow face (the "Component L" role that's currently undefined). Each pairing is shown on dark and light with real Start to Scale copy and a metric figure. T1 is today's Newsreader + Inter (Direction 0). Body type is the lowest-priority lever — react to the whole pairing.

03

Ascent motif

The "climbing / stepping up" metaphor stays — these are sharper executions of it, spanning ledger-bars, a rising baseline, scale-ticks, a stepped bracket/frame, a threshold plane, and a climbing node-path. Each is shown as a hero mark plus real usage contexts. M1 evolves today's "Three Steps" (Direction 0).
